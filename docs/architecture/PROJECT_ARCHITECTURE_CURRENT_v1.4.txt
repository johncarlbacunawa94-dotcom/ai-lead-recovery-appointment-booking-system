1. PLATFORM RESPONSIBILITIES
===============================================================================

RETELL AI

Owns:

- speech recognition;
- synthesized speech;
- interruption handling;
- turn-taking;
- Conversation Flow;
- approved conversational knowledge;
- conversational intent interpretation;
- approved synchronous tool invocation.

Retell does NOT own authoritative database state.

SUPABASE / POSTGRESQL

PostgreSQL is the authoritative system of record.

It owns:

- canonical calls;
- prospects;
- opportunities;
- appointments;
- human handoffs;
- contact points;
- contact eligibility;
- consent state;
- conversations;
- messages;
- tool execution audit;
- AI decisions;
- raw provider events;
- outbox events;
- outbound SMS-attempt state;
- lifecycle truth;
- deterministic business-state transitions.

SUPABASE EDGE FUNCTIONS

Own synchronous provider/application boundaries including:

- provider signature verification;
- provider transport validation;
- canonical context resolution;
- deterministic argument validation;
- idempotency;
- appointment-provider adapters;
- handoff creation;
- Twilio ingress;
- Twilio SMS transport adapter;
- protected recovery-SMS orchestration.

N8N

n8n remains asynchronous orchestration only.

It owns:

- outbox-event polling;
- asynchronous workers;
- post-call orchestration;
- retries;
- notifications;
- dead-letter alerts;
- missed-call recovery orchestration;
- inbound-SMS asynchronous reconciliation orchestration;
- scheduled processing.

n8n does not independently determine authoritative business state.

CAL.COM

Cal.com owns booking-provider availability and booking truth.

TWILIO

Twilio is the intended external SMS / PSTN transport.

Current portfolio implementation proves provider-contract integration but
does not claim live carrier/PSTN verification.

10. PHASE 6C - SAFE OUTBOUND RECOVERY SMS
===============================================================================

Implemented components include:

- prepare_twilio_missed_call_recovery_sms_v1;
- Twilio SMS transport adapter;
- durable outbound_message_attempts state;
- protected twilio-recovery-sms Edge Function;
- P6C - Missed-Call Recovery SMS Worker.

The safety gate re-checks authoritative state immediately before a send attempt.

Relevant controls include:

- exact contact resolution;
- SMS eligibility;
- DND;
- revoked consent;
- duplicate protection;
- durable attempt state.

Transport modes include:

- MOCK;
- LIVE.

Controlled transport outcomes include:

- success;
- provider rejection;
- retryable rejection;
- unknown network outcome.

UNKNOWN provider outcomes are preserved rather than blindly retried.

The published P6C n8n worker performs asynchronous orchestration only.

11. PHASE 6D - INBOUND SMS AND OPT-OUT
===============================================================================

Implemented components include:

- TWILIO_INCOMING_MESSAGE ingestion;
- reconcile_twilio_incoming_message_v1;
- authoritative message / conversation persistence;
- exact phone identity resolution;
- ambiguous identity preservation;
- provider MessageSid idempotency;
- deterministic STOP classification;
- deterministic consent revocation;
- deterministic DND enforcement;
- review outbox creation for unresolved / ambiguous identity;
- P6D - Twilio Inbound SMS Worker.

Recognized opt-out tokens include:

STOP
STOPALL
UNSUBSCRIBE
CANCEL
END
QUIT

OPT_OUT takes precedence over ordinary reply handling.

For resolved exact identities, SMS opt-out makes every supported SMS purpose:

INELIGIBLE

with:

dnd = true

and:

consent_basis = REVOKED

AI cannot reverse this state.

Controlled testing verified:

- normal inbound reply;
- replay;
- STOP;
- ambiguous normal reply;
- ambiguous STOP.

A remote synthetic normal-reply fixture also passed the complete:

ingest
-> claim
-> reconcile
-> persist
-> complete

path.

The synthetic remote fixture was subsequently removed.
